# capacita-FRONT-26-1

## Descrição
Esse foi um projeto feito na capacitação de front-end da Ecomp. Utiliza as tecnologias:
- HTML5
- CSS3
- JavaScript
- React

## Objetivo
O projeto foi desenvolvido com tecnologias ensinadas na capacita, tendo como principal missão exercitar e colocar em prática tudo que foi aprendido no período de aulas.
<br> A ideia foi desenvolver um site sobre algo que gostaríamos, decidi então juntar algumas coisas que gosto (gatinhos e jogos) e falar um pouquinho de mim.

## Desenvolvimento
Foi meu primeiro contato com o JS e React, então no ínicio tive dificuldade para pegar ritmo. Como eu já tinha tido um contato básico com HTML5 e CSS3 assim que compreendi o resto o projeto andou fluidamente.
